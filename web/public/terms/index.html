Términos de Uso

Última actualización: 28 de agosto de 2026

Resumen: CC Brew convierte tu idea en un CLAUDE.md listo para construir. Es un punto de partida generado con IA, no un producto terminado — revísalo antes de usarlo. La app cobra por proyecto (créditos sin vencimiento); el Skill + MCP para Claude Code es gratis.

1. Aceptación

Al usar CC Brew — la app web (ccbrew.kitifica.com), el Skill o el MCP para Claude Code — aceptas estos términos. Si no estás de acuerdo, no uses el servicio.

2. Descripción del servicio

CC Brew toma tu idea, tu marca y a quién querés convencer, y genera un cuestionario dirigido, un semáforo de viabilidad y un archivo CLAUDE.md con el brief listo para que Claude Code construya la herramienta. Se ofrece de dos formas:

  • App (PWA): desde el navegador, en ccbrew.kitifica.com, con planes de créditos de pago.
  • Skill + MCP: gratis, para usar directo desde Claude Code con el comando /cc-brew.

El resultado (cuestionario, semáforo, CLAUDE.md) es generado con inteligencia artificial y depende de la información que proporcionás. No sustituye tu propio criterio: revisalo antes de construir sobre él.

3. Cuenta

La app requiere una cuenta (correo y contraseña) para guardar tus proyectos y tu saldo de créditos. Sos responsable de mantener tus credenciales seguras y de toda actividad bajo tu cuenta.

4. Créditos y pagos

La primera cuenta arranca con 3 proyectos de prueba gratis. Los créditos adicionales se compran por planes (por ejemplo, 5, 12 o 20 proyectos) y no vencen. Cada crédito equivale a un proyecto completo (cuestionario + semáforo + CLAUDE.md). También existe "Trae tu API" — un pago único de $39 para usar tu propia clave de Anthropic con proyectos ilimitados, sin créditos ni renovación. No hay suscripción ni cobro recurrente automático — pagás solo cuando comprás más créditos o el acceso de por vida.

Las compras se procesan mediante un proveedor de pagos externo. Por tratarse de un bien digital consumido al generarse (el crédito se descuenta al completar el proyecto), las compras no son reembolsables salvo que la ley aplicable indique lo contrario. Si tuviste un problema real con una compra, escribinos a hola@kitifica.com.

5. Contenido y propiedad

Vos sos dueño de la idea, la información de marca y el material que subís, así como del CLAUDE.md y demás resultados que CC Brew genera para tu proyecto. Podés usarlos, editarlos y construir sobre ellos libremente.

Nos das permiso para procesar ese contenido (incluyendo enviarlo a proveedores de IA como Anthropic) únicamente con el fin de generar tu resultado. No usamos tu contenido para entrenar modelos ni lo compartimos con terceros salvo lo necesario para operar el servicio.

6. Uso aceptable

Al usar CC Brew, aceptás no:

  • Subir contenido ilegal, que infrinja derechos de terceros, o que busque generar material dañino a través de la IA.
  • Intentar comprometer la seguridad de la app, la API o las cuentas de otros usuarios.
  • Automatizar compras o abusar de los créditos gratuitos con múltiples cuentas.
  • Revender o redistribuir el acceso a la app o al MCP como si fuera propio.

7. Servicios de terceros

CC Brew depende de:

  • Anthropic / Claude: procesa tu idea para generar preguntas, semáforo y CLAUDE.md, sujeto a los Términos de Uso de Anthropic. El Skill y el MCP requieren una suscripción activa a Claude Code.
  • Supabase: almacena tu cuenta y tus proyectos, sujeto a sus términos.
  • Un proveedor de pagos externo para procesar la compra de créditos.

Kitifica no es responsable de cambios o interrupciones en estos servicios de terceros que afecten el funcionamiento de CC Brew.
