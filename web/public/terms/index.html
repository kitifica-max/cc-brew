2. Descripción del servicio

CC Controller es una herramienta para desarrolladores que permite controlar Claude Code CLI desde un dispositivo móvil mediante una PWA. Consiste en:

  • Una aplicación de escritorio Electron para macOS.
  • Una PWA (Progressive Web App) accesible desde cualquier navegador móvil moderno.
  • Un canal de comunicación en tiempo real usando Supabase Realtime.
