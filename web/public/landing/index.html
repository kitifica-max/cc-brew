Por qué funciona · La investigación detrás

Los 3 fracasos que hacen que una herramienta no convenza — y cómo los resuelve

Analizamos por qué las herramientas construidas con IA no logran convencer al cliente que las ve. El patrón se repite: la herramienta funciona — pero no resuelve la objeción real, no suena a la marca, o nadie puede medir si convenció. Cada criterio del semáforo mapea a uno de estos fracasos.

Sin esto → falla

Claridad de la objeción

Sin saber qué objeción hay que resolver, Claude Code construye "una herramienta bonita" que no ataca el precio, la confianza o la urgencia real del cliente.

↳ CC Brew la extrae antes de arrancar
Sin esto → falla

Lineamientos de marca

Sin marca definida, la herramienta sale con colores y tono genéricos. El cliente nota que no es "de la empresa" — y eso resta credibilidad justo cuando más importa.

↳ Se consolidan desde tu web, imágenes o documento
Sin esto → falla

Forma de medir si convenció

Sin una reacción esperada definida — pide cotización, agenda llamada, dice que sí — nadie sabe si la herramienta funcionó o solo se vio bien.

↳ Se define antes del semáforo, no después
CC Brew no es un editor de plantillas. Es el proceso de preparación que separa "esto sí convence" de "volvamos a empezar."

FAQ

¿Para qué pagar créditos si hay una forma gratis?
La ruta gratuita requiere tener Claude Code CLI instalado en tu equipo y estar sentado frente a él. La IA de Kitifica (App Directa) funciona desde cualquier dispositivo, en cualquier momento — tu celular, una tablet, el equipo de otra persona. El valor de los créditos es ese: capturar y estructurar la idea ahí donde se te ocurrió, no cuando llegues al escritorio. Si ya tienes tu propia API key de Anthropic y generás muchos proyectos, Trae tu API ($29, precio especial · pago único) te da proyectos ilimitados para siempre, sin comprar más créditos. Para quienes trabajan con Claude Code todo el día, la ruta gratuita es perfecta. Para los demás, App Directa — o el pago único si generás con frecuencia — es lo que tiene sentido.
¿Qué es un crédito de procesamiento?
1 crédito = 1 proyecto completo (cuestionario + semáforo + CLAUDE.md). Se descuenta una sola vez, cuando tu CLAUDE.md queda listo — sin importar cuántas veces lo revises o pidas mejorarlo después.
¿Los créditos vencen?
No. Los créditos que compres quedan en tu cuenta sin fecha de expiración. Úsalos a tu ritmo.
¿Puedo usar mi propia API key en vez de pagar por créditos?
Sí. Con el plan "Trae tu API" ($39, pago único) conectas tu propia API key de Anthropic y tienes proyectos ilimitados para siempre, sin comprar más créditos. Solo se aceptan API keys de Anthropic. Tu clave se guarda encriptada y nunca se usa para otro fin que no sea procesar tus propios proyectos.
¿Cómo funciona la ruta gratuita con Claude Code?
Si tienes Claude Code CLI instalado, tienes dos opciones gratuitas: (1) Selecciona "Claude Code local" en ⚙️ dentro de la app — CC Brew usa tu Claude Code como motor. (2) Instala el Skill y el MCP para ejecutar CC Brew directamente desde el chat con /cc-brew, sin abrir la app. Los comandos están en la sección Skill de esta página.
¿Qué es el Skill de CC Brew y cómo lo instalo?
El Skill es un archivo (SKILL.md) que le enseña a Claude Code cómo ejecutar el flujo completo de CC Brew desde el chat. La forma más fácil de instalarlo es con el instalador automático: descárgalo desde /instalar o ejecuta bash <(curl -fsSL https://ccbrew.kitifica.com/instalar/install.sh) en tu terminal. Instala el MCP y el Skill en un solo paso.
¿Funciona en Android? ¿En Windows?
Sí. CC Brew es una PWA que funciona en cualquier dispositivo con navegador moderno — iOS, Android, Windows, macOS, Linux. Instálala desde el navegador como app nativa.
¿Qué es el CLAUDE.md y para qué sirve?
Es el documento de instrucciones que Claude Code lee al iniciar. Describe qué construir, el flujo principal, qué está fuera de alcance y el stack sugerido. Con un buen CLAUDE.md, Claude Code construye exactamente lo que pediste — sin pedirte aclaraciones.
¿Y si la herramienta necesita cambios antes de estar lista?
Toda herramienta se pule antes de convencer. Le pedís el ajuste a Claude Code en lenguaje natural — cambiá esto, mejorá aquello — y la vas afinando hasta la versión final, sin depender de un editor externo ni de un tercero.
¿Qué son la Fase 1 y la Fase 2 en el documento?
La Fase 1 es la primera versión funcional: solo el núcleo de la app, sin complejidad extra. La Fase 2 describe la visión de crecimiento pero está marcada como bloqueada — para que Claude Code construya algo real y terminado en la primera sesión, no una app a medias.
¿Mis ideas quedan guardadas?
Los proyectos se guardan localmente en tu dispositivo. El texto de tu idea y el CLAUDE.md generado viven en tu sesión. No almacenamos ni leemos el contenido de tus ideas más allá del procesamiento necesario para generar el documento.
