Descargar CC Controller →

Conecta tu iPhone

Abre ccc.kitifica.com en Safari desde tu iPhone. Crea tu cuenta y empareja tu dispositivo con el código del tray.

Requiere Claude Code CLI instalado en tu Mac.

Instalación

Tres pasos. Sin configuración.

1

Instala CC Controller

Vía Homebrew (recomendado) o descargando el DMG. Apple Silicon e Intel.

brew install --cask kitifica-max/tap/cc-controller Descargar DMG →
2

Instala Claude Code

Si todavía no lo tienes, instala Claude Code CLI. Disponible para macOS, Linux y Windows.

Instalar Claude Code →
3

Conecta tu iPhone

Abre ccc.kitifica.com desde Safari, crea tu cuenta y pega el código de emparejamiento del tray. Listo.

¿macOS bloqueó la aplicación? (solo si usas el DMG)

Si instalas con Homebrew, macOS no bloqueará la app. Si descargaste el DMG manualmente:

  1. Ve a Configuración del Sistema → Privacidad y Seguridad
  2. Busca el mensaje sobre CC Controller y haz clic en "Abrir igualmente"
  3. Confirma en el diálogo que aparece

Solo necesitas hacerlo una vez. El código fuente está disponible en GitHub para que puedas auditarlo.
