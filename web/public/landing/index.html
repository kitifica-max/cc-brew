Por qué

Claude Code trabaja en tu Mac.
Tú decides desde dónde.

01

Trabaja sin estar pegado a la pantalla

Inicia un refactor largo, un análisis de código o una generación de features. Claude trabaja en tu Mac mientras tú estás en el café, en una reunión o en el sofá. Revisas el progreso desde el iPhone y respondes cuando lo necesita.

02

Sin SSH, sin túneles, sin abrir puertos

Supabase actúa de puente en tiempo real. Tu Mac nunca expone un puerto al exterior. No hay VPN que configurar, no hay ngrok, no hay nada que mantener. Descargas la app, generas un código de emparejamiento y conectas.

03

El CLI real, no un wrapper de API

CC Controller ejecuta claude --print directamente en tu Mac con acceso total a tus archivos, tu PATH y tus herramientas. No es un chatbot genérico. Es la misma experiencia de Claude Code que ya usas, controlada desde el móvil.

Arquitectura

Tres piezas. Sin complejidad
innecesaria.

1

PWA recibe tu prompt

Inicias sesión en la PWA y escribes desde el iPhone. El mensaje viaja por un canal privado de Supabase Broadcast, con token de sesión validado en cada evento.

sendEvent('input', { text, token })
2

Electron ejecuta Claude

El desktop recibe el evento, valida el token y ejecuta claude --print dentro del directorio del proyecto activo en tu Mac.

claude --print --continue
3

Streaming token a token

Cada chunk de stdout llega como evento chunk por Supabase Broadcast. La PWA muestra texto creciendo en vivo con cursor naranja. Al terminar, el mensaje queda en historial.

broadcast('chunk', { text, done })
Electron 30 Tray app, gestiona procesos Claude, escribe proyectos y .env en disco local Mac · Node.js
Next.js 14 PWA instalable, UI de chat, subida de archivos, configuración de modelo iPhone · Netlify
Supabase Canal Broadcast para mensajes (sin DB), Storage para archivos en tránsito Backend · Realtime
Netlify Deploy automático de la PWA, variables de entorno por interfaz gráfica CDN · Edge
Seguridad

Sin firma de Apple.
Con código que puedes leer.

El DMG no está notarizado. Lo que sí existe es código abierto: puedes leer main.js, bridge.js y pty.js antes de ejecutar cualquier cosa.

Código de emparejamiento

Tu canal es privado: Supabase solo deja entrar a tu cuenta. Encima va el token del setup + tu SESSION_ID único; sin ese par exacto, cualquier evento llega y se descarta en silencio.

SESSION_ID + SESSION_TOKEN

Sin puertos abiertos

El Mac no escucha en ningún puerto. Todo viaja por Supabase WebSocket (WSS/TLS). Sin SSH, sin túneles ngrok, sin IP del Mac expuesta en internet.

wss:// solo — 0 puertos locales

Path traversal bloqueado

Electron valida que toda ruta de archivo quede dentro de ~/CCProjects/. Rutas absolutas o con ../ rechazadas explícitamente.

destPath.startsWith(project.path + sep)

Whitelist de archivos

Solo extensiones permitidas (.png .jpg .pdf .txt .md .json .csv .svg .zip). Máx. 10 MB. El archivo se elimina de Supabase Storage inmediatamente tras descargarse.

ALLOWED_EXTENSIONS · MAX_FILE_BYTES

Secretos con permisos 600

Las variables de entorno se guardan en ~/CCProjects/<slug>/.env con mode 0o600. Solo el usuario del sistema puede leerlas.

writeFileSync(path, data, {mode: 0o600})

Código abierto y auditable

El repositorio completo está en GitHub. Antes de instalar puedes revisar cada línea. No hay código ofuscado ni binarios de terceros sin fuente.

Instalación

Listo en 5 minutos

1

Descarga e instala

Descarga el DMG, ábrelo y arrastra CC Controller a tu carpeta de Aplicaciones.

Descargar DMG (Apple Silicon) Descargar DMG (Intel)
macOS bloqueará la app al primer intento

Es normal — el DMG no está firmado por Apple. La PWA sí está verificada (Lighthouse: 99 Performance · 100 Best Practices · PWA instalable). Para abrir la app de escritorio:

  1. Ve a Configuración del Sistema → Privacidad y Seguridad
  2. Baja hasta ver "CC Controller fue bloqueado…"
  3. Haz clic en Abrir de todas formas
  4. Confirma con Abrir de todas formas en el diálogo
