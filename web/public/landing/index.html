Los 4 tipos de nodo

Cada nodo tiene un rol.

No son notas sueltas. Cada tipo le dice a Claude Code exactamente qué información está leyendo — y cómo construir con ella.

Conversación

La idea en palabras

Describe tu idea libremente. El AI hace preguntas, genera preguntas guía y estructura el contexto central del proyecto.

→ Claude Code leerá esto primero
Definición

El alcance exacto

Define qué incluye el POC y qué queda fuera. Cuanto más específico, menos alucinaciones en la generación.

→ Delimita el scope del build

Funciones clave

Todo lo que necesitas, listo para usar.

Canvas con pinch-to-zoom

Pan y zoom táctil en el mapa completo. Coloca nodos donde tiene sentido conceptualmente, no donde cabe en pantalla.

Vectores con flechas

Conecta nodos con flechas que muestran el flujo de información. Claude Code lee las relaciones, no solo el contenido aislado.

Skills incluidos, cero setup

UI/UX pro-max e iconos Lucide vienen bundleados. Claude Code los usa automáticamente en cada proyecto — sin que el usuario instale nada.

Guía paso a paso

Un stepper contextual vive en el canvas y se actualiza solo conforme completas cada nodo y conexión.

Modelo y esfuerzo configurables

Elige el modelo de Claude y el nivel de esfuerzo por proyecto. claude-sonnet, opus o haiku — tú decides el trade-off.

Preguntas frecuentes

FAQ

CC Creator es completamente gratis y Open Source. Solo necesitas tu propia suscripción a Claude Code de Anthropic para ejecutar el build.
Mediante Supabase Realtime. La PWA en tu iPhone y la app de escritorio en tu Mac se sincronizan en tiempo real. Tu cuenta de Supabase (gratuita) actúa como bridge. El código de tu proyecto nunca pasa por ahí — solo el contexto del mapa.
Cada tipo de nodo le dice a Claude Code qué tipo de información está recibiendo. Conversación es el contexto libre. Definición delimita el alcance. Referencia agrega documentos y archivos externos. Proceso describe el flujo de usuario. Juntos forman un prompt estructurado, no texto libre.
Lo que Claude Code pueda construir, CC Creator puede estructurarlo: apps web, APIs, scripts, CLIs, apps móviles. CC Creator no limita el tipo de proyecto — solo organiza el contexto para que Claude Code arranque con toda la información necesaria.
El mapa de nodos se guarda en tu cuenta de Supabase (que tú controlas). Claude Code ejecuta en tu Mac. Nada pasa por servidores de terceros más allá de lo que Supabase gestiona para el bridge en tiempo real. El código es Open Source — puedes auditarlo tú mismo.
